# UT Voice · 文字发声器

> 每个字符一个 blip，不是配音。让文字像 Undertale 里的角色那样"说话"。

Undertale 里角色开口时，没有真人语音——是一串极短的音效，每个字符触发一次，音高微微抖动。所以它听起来像有人在说话，实际上一个音节都没说。

这个项目把那个机制还原出来：**纯数学合成，没有采样任何一个原版音频文件。**

---

## 两种用法

### 1. 网页版（`index.html`）

双击打开，或者直接访问 GitHub Pages。

- 文字打进输入框，点 **▶ 说话**，它一个字一个字地吐音
- 上面一排切换角色音色，点哪个就用哪把嗓子试听一句
- 三个滑块：语速、音高抖动、音量
- **⧉ 复制分享链接** —— 生成一条带文本的 URL，别人点开就直接念

也可以手动拼 URL：

```
index.html?v=sans&t=heh.+ok.&auto=1
```

`v` 是音色，`t` 是要念的文本，`auto=1` 自动播放。

### 2. 命令行版（`ut_say.py`）

纯标准库，零依赖，Python 3.8+。

```bash
python ut_say.py "heh. ok."
python ut_say.py -v papyrus "NYEH HEH HEH!"
python ut_say.py -v toriel -f lines.txt -o out.wav
echo "my child..." | python ut_say.py -v toriel
```

参数：

| 参数 | 说明 |
|---|---|
| `-v, --voice` | 音色，见下表 |
| `-f, --file` | 从文本文件读 |
| `-o, --out` | 输出 wav 路径 |
| `-s, --speed` | 语速倍率，越小越快 |
| `-j, --jitter` | 音高抖动 0–0.3 |
| `--vol` | 音量 0–1 |
| `--seed` | 固定随机种子，结果可复现 |
| `--no-play` | 只生成不播放 |

## 音色

| key | 基频 | 波形 | 性格 |
|---|---|---|---|
| `sans` | 112 Hz | square | 懒、低、不使劲 |
| `papyrus` | 330 Hz | square | 又快又亮，全力 |
| `toriel` | 214 Hz | triangle | 软，妈妈的调 |
| `flowey` | 545 Hz | square | 尖、短、笑里藏刀 |
| `undyne` | 268 Hz | sawtooth | 粗，带毛刺 |
| `alphys` | 404 Hz | triangle | 抖，音高老飘 |
| `blook` | 96 Hz | sine | 虚，像叹气 |
| `maxiang` | 74 Hz | sine | 深水里的低鸣，慢 |

## 它是怎么响的

四个决定味道的细节：

1. **每字符一次触发，很短。** 30–85 ms，方波/三角/锯齿/正弦任选。
2. **音高随机抖 ±6%。** 这一条最关键——不抖就像电报机，抖了才像嗓子在晃。
3. **标点不发声，只拉长停顿。** 逗号 150 ms、句号 250 ms、换行 340 ms。UT 那种"说到一半停下来"的感觉是这个给的。
4. **问号音高上扬 22%，感叹号 10%。** 同一句话加个问号，听起来就真的在问。

包络是 4 ms 起音 → 保持 → 12 ms 平方衰减，用来防爆音。

## 关于"像不像原版"

**像，但不是。** 原版的 blip 是采样，带噪声和带宽限制，听起来"沙"，像老游戏机；这版是干净的正弦/方波，更电子。参数是按听感调的，不是从游戏包里量的。

好处是：全部只有几十行数学，改哪个数字立刻听得出差别。原版采样你改不了。

想要真家伙，得把游戏里的 `snd_txtsans` 之类拆出来做采样，再套这套时序引擎。那是另一条路。
